# АВТОСКЛАД-24 · Серверная часть (MySQL + PHP + пользователи)

Эта папка содержит всё, что нужно для хранения данных склада **в базе SQL**
на любом хостинге с PHP и MySQL (обычный shared-хостинг подходит).

```
server/
├── database.sql   ← база: таблицы + демо-данные (импортируется в phpMyAdmin)
├── api.php        ← PHP-API (регистрация, вход, сессии, чтение/запись склада)
├── config.php     ← настройки подключения к БД и ключ доступа
└── README.md      ← эта инструкция
```

---

## Шаг 1. Создайте базу данных на хостинге

1. Откройте панель хостинга → раздел **«Базы данных MySQL»**.
2. Создайте базу, пользователя и пароль. Пример:
   - база: `autosklad24`
   - пользователь: `autosklad24_user`
   - пароль: (сложный, сгенерированный панелью)
3. Назначьте пользователя базе с полными правами.

## Шаг 2. Импортируйте `database.sql`

**Через phpMyAdmin:**
1. phpMyAdmin → слева выберите созданную базу → вкладка **«Импорт»**.
2. Файл: `server/database.sql` → «Вперёд».
3. Готово: появятся таблицы `users`, `sessions`, `cars`, `deleted_cars`,
   `stock_meta` и 6 демонстрационных автомобилей.

**Через консоль (SSH):**
```bash
mysql -u autosklad24_user -p autosklad24 < database.sql
```

> Файл идемпотентен: повторный импорт безопасен, а при обновлении со старой
> версии он сам добавит колонки `last_editor`, `last_editor_id`,
> `last_edited_at` в таблицу `cars`.

## Шаг 3. Загрузите PHP-файлы

Загрузите `api.php` и `config.php` в папку сайта, например:

```
/public_html/api/api.php
/public_html/api/config.php
```

## Шаг 4. Настройте `config.php`

Отредактируйте загруженный `config.php`:

```php
const DB_HOST = 'localhost';
const DB_NAME = 'autosklad24';          // из шага 1
const DB_USER = 'autosklad24_user';     // из шага 1
const DB_PASS = 'ваш_пароль';           // из шага 1
const API_KEY = 'любой-сложный-ключ';   // рекомендуется; можно оставить ''
```

## Шаг 5. Подключите сайт к API

Откройте `src/sync.ts` в исходниках сайта и заполните:

```ts
export const SQL_API_URL = "https://ваш-домен.ru/api/api.php";
export const SQL_API_KEY = "любой-сложный-ключ"; // тот же, что в config.php
```

Затем пересоберите сайт (`npm run build`) и выложите `dist/`.

## Шаг 6. Проверьте

Откройте в браузере:

```
https://ваш-домен.ru/api/api.php?do=me
```

Должен вернуться JSON `{"ok":false,"error":"Требуется вход в систему"}` —
значит, API работает и защищён.

## Пользователи и роли

- Сотрудники регистрируются прямо на сайте (экран входа → «Регистрация»).
- Пароли хранятся в базе в виде хеша (`password_hash`, bcrypt) — в открытом
  виде пароль нигде не записывается.
- **Первый зарегистрированный пользователь автоматически получает роль
  `admin`**, все последующие — `operator`. Роль отображается в шапке терминала.
- Сессия живёт 30 дней, токен хранится в таблице `sessions`.
- Логин: 3–20 символов (латиница, цифры, «_»), пароль: от 6 символов.

## Кто редактировал автомобиль

- При каждом сохранении (приёмка или правка) терминал записывает в базу
  имя пользователя в колонки `cars.last_editor`, `cars.last_editor_id`,
  `cars.last_edited_at`.
- Если клиент по какой-то причине не передал редактора, API подставляет
  текущего авторизованного пользователя.
- На карточке автомобиля строка «Ред.: Имя · дата и время» видна всем
  сотрудникам. Автор первичной приёмки сохраняется отдельно (`cars.op_code`
  и поле «принял» на карточке).

## Эндпоинты API

| Метод | URL | Токен | Назначение |
|-------|-----|-------|------------|
| POST | `api.php?do=register` | — | `{login, name, password}` → `{ok, token, user}` |
| POST | `api.php?do=login` | — | `{login, password}` → `{ok, token, user}` |
| GET  | `api.php?do=me` | ✔ | Текущий пользователь |
| POST | `api.php?do=logout` | ✔ | Закрыть сессию |
| GET  | `api.php?do=pull` | ✔ | Весь склад: `{cars, deleted, rev, savedAt}` |
| POST | `api.php?do=push` | ✔ | Сохранить склад целиком (JSON в теле) |

Токен передаётся в заголовке `X-Auth-Token`; ключ доступа (если задан) —
в заголовке `X-Api-Key`.

## Резервное копирование

Экспорт всей базы (панель хостинга → phpMyAdmin → «Экспорт»), либо:

```bash
mysqldump -u autosklad24_user -p autosklad24 > autosklad24-backup.sql
```

Фотографии хранятся в колонке `cars.photo` (сжатые JPEG base64, до ~200 КБ
на машину) — при экспорте базы сохраняется всё.
