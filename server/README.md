# АВТОСКЛАД-24 · База данных SQL: импорт и подключение

Эта папка содержит всё, чтобы хранить склад автомобилей в настоящей базе
данных MySQL на вашем хостинге:

| Файл          | Назначение                                                        |
| ------------- | ----------------------------------------------------------------- |
| `database.sql`| Схема базы (3 таблицы) + демонстрационные автомобили              |
| `config.php`  | Настройки подключения к базе (заполняете свои)                    |
| `api.php`     | PHP-API: `?do=pull` — чтение склада, `?do=push` — сохранение      |

Требования хостинга: **MySQL 5.7+ / MariaDB 10.2+** и **PHP 7.4+**
(есть практически на любом shared-хостинге: Timeweb, REG.RU, Beget, SprintHost и т.п.).

---

## Шаг 1. Создать базу данных на хостинге

1. Зайдите в панель хостинга → раздел **«Базы данных MySQL»**.
2. Создайте базу, например `autosklad24`.
3. Создайте пользователя, например `autosklad24_user`, с надёжным паролем.
4. Выдайте пользователю **все права** на базу `autosklad24`.
5. Запишите: имя базы, имя пользователя, пароль (хост почти всегда `localhost`).

## Шаг 2. Импортировать `database.sql`

**Вариант А — через phpMyAdmin (проще всего):**

1. Откройте **phpMyAdmin** в панели хостинга.
2. Слева выберите созданную базу `autosklad24`.
3. Откройте вкладку **«Импорт»**.
4. Нажмите «Выберите файл» → укажите `database.sql` из этой папки.
5. Нажмите **«Вперёд»**. Готово: созданы таблицы `cars`, `deleted_cars`,
   `stock_meta` и загружены 6 демонстрационных автомобилей.

**Вариант Б — через SSH-консоль:**

```bash
mysql -u autosklad24_user -p autosklad24 < database.sql
```

## Шаг 3. Загрузить PHP-файлы на хостинг

1. Создайте в корневой папке сайта папку `api` (например, `public_html/api`).
2. Загрузите в неё через файловый менеджер или FTP два файла:
   `config.php` и `api.php`.
3. Откройте в браузере `https://ваш-домен/api/api.php?do=pull` —
   должен вернуться JSON со списком машин. Если видите ошибку подключения —
   проверьте данные из шага 1.

## Шаг 4. Заполнить `config.php`

Откройте загруженный `config.php` и впишите свои значения:

```php
const DB_NAME = 'autosklad24';        // из шага 1
const DB_USER = 'autosklad24_user';   // из шага 1
const DB_PASS = 'ваш_пароль';         // из шага 1
const API_KEY = 'любой-сложный-ключ'; // рекомендуется задать
```

## Шаг 5. Подключить сайт к базе

1. Откройте в проекте файл `src/sync.ts`.
2. Заполните константы:

```ts
export const SQL_API_URL = "https://ваш-домен/api/api.php"; // если сайт и API на одном
                                                              // домене, можно "api/api.php"
export const SQL_API_KEY = "любой-сложный-ключ";              // тот же, что в config.php
```

3. Пересоберите сайт: `npm run build`.
4. Загрузите содержимое папки `dist/` на хостинг.

Всё: теперь каждый терминал компании при открытии страницы получает склад
из базы MySQL, а приёмка / правка / списание машин сразу сохраняются в базу
и видны всем коллегам.

---

## Структура базы

| Таблица        | Что хранит                                                                |
| -------------- | ------------------------------------------------------------------------- |
| `cars`         | Единицы склада: марка, модель, год, страна, комплектация, пробег, привод, объём и тип двигателя, мощность, КПП, цвет, цена, фото (LONGTEXT), коды оператора, даты |
| `deleted_cars` | Идентификаторы списанных машин (синхронизация удалений между терминалами) |
| `stock_meta`   | Ревизия склада и время последнего сохранения                              |

## Полезные команды

```bash
# Резервная копия базы
mysqldump -u autosklad24_user -p autosklad24 > backup.sql

# Очистить склад (оставив структуру)
mysql -u autosklad24_user -p autosklad24 -e "DELETE FROM cars; DELETE FROM deleted_cars;"

# Посмотреть склад
mysql -u autosklad24_user -p autosklad24 -e "SELECT make, model, year, price FROM cars;"
```

## Примечания

- Пока `SQL_API_URL` в `src/sync.ts` пустой, сайт использует резервное
  облачное хранилище — ничего настраивать не нужно, можно пользоваться сразу.
- Фотография каждой машины хранится в поле `photo` в сжатом виде
  (JPEG ~720 px), поэтому база растёт медленно.
- Не публикуйте `config.php` в открытых репозиториях — в нём пароль от базы.
