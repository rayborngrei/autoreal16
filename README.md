# АвтоСклад-24 — внутренний терминал приёмки автомобилей

Внутренний сайт автосалона: каталог автомобилей на складе + приёмка новых
единиц **голосовым набором**.

## Возможности

- **Голосовая приёмка** — сотрудник диктует характеристики в микрофон
  (Web Speech API, `ru-RU`), система распознаёт и автоматически подставляет
  в форму: марку, модель, год, страну, комплектацию, пробег, привод,
  объём двигателя, коробку передач, цвет и цену
  (включая числительные: «два миллиона восемьсот девяносто тысяч» → 2 890 000 ₽).
- **Карточка единицы** — фото (drag & drop, сжимается автоматически),
  все 10 характеристик блоками, номер единицы, дата приёма.
- **Каталог** — поиск, фильтры (привод / коробка), 5 сортировок,
  сводка склада (единиц, общая стоимость, средний чек, средний пробег),
  лента последних поступлений, списание с подтверждением.
- Данные хранятся в `localStorage` браузера терминала.

## Запуск

```bash
npm install
npm run dev       # режим разработки
npm run build     # продакшен-сборка в dist/
```

## Стек

React 18 · TypeScript · Vite · Tailwind CSS 4 · Web Speech API · JSZip

## Примечание о фото

Фотографии демо-склада подгружаются по внешним URL (указаны в `src/seed.ts`).
Фото новых единиц хранятся в `localStorage` в сжатом виде (JPEG).
